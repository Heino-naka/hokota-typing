# 日本一のやさいのまち　鉾田市タイピング探検

鉾田市のことば（町域・学校・海・やさい・メロン・歴史など）をローマ字で打ちながら、「ふるさとカード」を集める、無料のタイピングゲームです。パソコン・Chromebook向け。登録不要で、記録は使っている端末の中だけに保存されます。

- 遊ぶ：https://heino-naka.github.io/hokota-typing/
- つくった人：へいなか（https://heino-naka.github.io/）
- いばらきタイピング探検MAP：https://heino-naka.github.io/ibaraki-typing-map/

## 内容
- 60秒のタイピング（かんたん／ふつう／むずかしい）と、時間を気にせず練習できる「れんしゅう」
- ふるさとカード145枚（ガチャで集める）、集める町域は61か所（すべて集めると証書）
- コインは「メロン」

## ご利用について
学校・自治体・ご家庭では、自由にお使いください。

このゲームは、紹介してもらうことが何よりの励みです。リンクを送ったり、SNSやLINEで紹介したり、スクリーンショットを投稿したりすることは、大歓迎です。

ゲームのファイルを、作り変えて配ったり、売ったりすることは、ご遠慮ください。作者名の表示は、そのままにしてください。

## 掲載している名前について
学校・園・施設などの名前は、公式の名称を使っています。評価や比較を目的にした表示はしていません。内容でお気づきのことがあれば、作者までお知らせください。
